Entry for the [make.fun bounty "What the Elevator Would Say"](https://make.fun/bounty/u-eager-stork-81-9647-what-the-elevator-would-say-90844958): the funniest one line a talking elevator could say, at most 120 characters, in the elevator's own voice.

> I am sorry. I cannot move with eight people and a fridge. One of you has to admit you are the fridge.

101 characters. One concept — the weight limit — with a turn that lands on the first read.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
